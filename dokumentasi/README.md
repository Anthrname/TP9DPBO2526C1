# Folder Dokumentasi

Folder ini berisi file rekaman dan animasi demonstrasi pengujian aplikasi berarsitektur **Model-View-Presenter (MVP)** untuk **Tugas Praktikum 9 & 10 DPBO**:

1. **`demo.gif`**: Animasi GIF demonstrasi beresolusi 800px yang menampilkan pengujian seluruh alur CRUD untuk modul Kandidat Karyawan dan Lowongan Pekerjaan.
2. **`TP10_Demo.mp4`**: Rekaman video asli resolusi penuh hasil demonstrasi alur program dari penambahan (*Create*), penampilan daftar (*Read*), pengubahan data ber-prefill (*Update*), hingga penghapusan (*Delete*).
